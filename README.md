# Planets Website 🌌
https://github.com/user-attachments/assets/76710af1-42a9-4c65-bb88-c16499919cbe

An interactive 3D solar system visualization built using Three.js, GSAP, and Vite. Explore planets with smooth animations and dynamic information updates as you navigate through the solar system.

## Features
- 🌍 3D Planet Models: Realistic 3D representations of planets with high-quality textures.
- 🎥 Smooth Transitions: GSAP-powered animations for seamless planet transitions.
- 📜 Dynamic Information: Displays planet-specific details like distance from Earth, atmosphere composition, and more.
- 🖱️ Interactive UI: Navigate through planets using a "Next Planet" button.
- 🔄 Rotating Planets: Each planet rotates dynamically for added realism.

## How It Works
### Planet Navigation:
- Clicking the "Next Planet" button moves the current planet out of view and brings the next planet into focus.
- The UI dynamically updates the planet's name, description, distance from Earth, and other details.
## Animations:
- GSAP is used to animate the transitions between planets.
- Each planet has its own rotation animation for added realism.

## Planets Included
- Mars: The Red Planet with a thin atmosphere.
- Neptune: Known for its deep blue color and strong winds.
- Jupiter: The largest planet in the solar system.
- Saturn: Famous for its stunning rings.
- Moon: Earth's only natural satellite.
- Earth: The only planet known to harbor life.

## Usage
* Open the app in your browser.
- Click the "Next Planet" button to navigate through the planets.
- Watch the planets transition smoothly and read their updated information.
